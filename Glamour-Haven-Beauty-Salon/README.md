# Glamour Haven Beauty Salon 🌸

A premium, full-featured web application for a modern beauty salon, designed to provide a seamless booking experience and a stunning visual showcase of services and expertise.

![Glamour Haven Banner](https://images.unsplash.com/photo-1560066984-138dadb4c035?ixlib=rb-1.2.1&auto=format&fit=crop&w=1950&q=80)

## ✨ Key Features

- **📱 Beautiful Responsive Design**: A mobile-first, professional interface built with vanilla CSS, featuring glassmorphism and smooth micro-animations.
- **⚡ Performance Optimized**: High-quality, web-optimized assets ensure ultra-fast loading times.
- **📅 Service Booking System**: Robust backend for managing salon services, employee assignments, and customer appointments.
- **👥 Team Showcase**: Dedicated section highlighting the expertise and specializations of the beauty professionals.
- **🖼️ Interactive Gallery**: A visually appealing showcase of transformations and salon results.
- **🔐 Secure Authentication**: Full customer registration and login system with session management.
- **💬 Customer Reviews**: Integrated review system to build trust and social proof.

## 🛠️ Tech Stack

- **Frontend**: JSP (JavaServer Pages), JSTL, Vanilla CSS, JavaScript.
- **Backend**: Java Servlets, Maven.
- **Animation**: AOS (Animate On Scroll) library for elegant reveal animations.
- **Icons & Fonts**: FontAwesome 6, Google Fonts (Playfair Display, Poppins).

## 🚀 Recent Optimizations

- **Image Optimization**: Migrated from massive 35MB assets to web-ready optimized images, reducing total page weight by 95%.
- **Architecture**: Implemented a global prelude/coda structure for consistent headers and footers across all pages, improving maintainability and reducing code redundancy.
- **Error Resolution**: Cleaned up legacy JSP structural conflicts and resolved all JSTL resolution issues for a production-ready codebase.

## 📦 Getting Started

### Prerequisites
- JDK 11 or higher
- Apache Tomcat 9.0+
- Maven 3.6+

### Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/yourusername/glamour-haven.git
   ```
2. Build the project:
   ```bash
   mvn clean install
   ```
3. Deploy the resulting `.war` file to your Tomcat server.
